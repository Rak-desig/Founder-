# Mango Market Mobile App

A simple React Native (Expo) mobile app concept for selling mangoes.

## Features
- Home screen with mango catalog cards
- Search input UI for mango varieties
- Promotional daily farm deal section
- Add-to-cart styled actions

## Run locally
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the Expo dev server:
   ```bash
   npm run start
   ```
3. Open with Expo Go on your phone, or launch iOS/Android simulator.
